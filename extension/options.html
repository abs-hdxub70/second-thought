Second Thought · 再想想

Checkout Pause settings

The extension only runs on shopping sites. It sends the price, product title and shop name to the Second Thought app on this computer, nothing else and nowhere else. 扩展只在购物网站运行，只把价格、商品名和店铺名发给本机上的「再想想」应用。

Language · 语言

Connect to the app · 连接应用

Start the app's local API with python -m second_thought.extension_api and type the pairing code it shows. 启动本地接口后输入显示的配对码。

When to ask · 什么时候问

Offline numbers (used when the app is not running) · 离线数字
